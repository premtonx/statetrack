This server was built without the web console

The REST and WebSocket API, agent gRPC ingestion and /metrics are running, but the React console was not compiled into this binary.

Build it and rebuild the server:

cd web && npm ci && npm run build ./scripts/release.sh <version>

Or run the official image, which already contains the console:

docker run -d -p 8080:8080 -p 50051:50051 -e DATABASE_URL=... ghcr.io/premtonx/statetrack:latest
